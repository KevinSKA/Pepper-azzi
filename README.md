## Project Overview
Pepper-azzi is an interactive Human-Robot Interaction (HRI) project developed using the Pepper humanoid robot as an AI teaching assistant in a classroom environment at USEK.

The system was designed to improve student engagement through:
- Speech interaction
- AI-powered Q&A
- Tablet-based interfaces
- Face recognition attendance
- Interactive quizzes
- AI image filters
- Survey and feedback collection

The project connects Pepper with external laptop systems, Gemini AI, face recognition, Gmail automation, and image processing to create an interactive and engaging educational experience.

---

## Features
- AI-powered real-time question answering using Gemini AI
- Face recognition attendance system
- Automated attendance Excel report generation
- Email system for sending reports to instructors
- Interactive student-based pop quizzes
- AI image filters and fun photo effects
- Pepper tablet interaction and educational visual support
- Gesture animations and entertainment activities
- QR-code based survey and rating system

- Face Recognition
- OpenCV
- Gmail API / SMTP

## Maria Kanaan & Tatiana Abi Fadel

- Attendance system and email sending automation

- 5-star survey system with QR code integration

### Challenges Faced
- Images sometimes showed only on the web and not on Pepper’s tablet.
- AI filters and effects were not always applied correctly.
- Some images did not display properly or did not appear at all.
- Synchronization issues occurred between Pepper’s animations and voice.
- Attendance emails sometimes failed to send due to connection and authentication issues.

## Conclusion
This project demonstrated how social robots can improve modern educational environments by combining AI, robotics, and interactive technologies. Pepper successfully acted as an engaging teaching assistant capable of interacting with students, answering questions, managing attendance, and creating an enjoyable learning experience.

Despite technical challenges related to synchronization, communication, and camera processing, the final system showcased the strong potential of HRI technologies in smart classrooms.
